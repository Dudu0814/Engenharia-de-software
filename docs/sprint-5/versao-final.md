# Versão final — StudyLink

## Objetivo

O StudyLink é uma plataforma acadêmica para aproximar estudantes por disciplina e interesse de estudo. A versão final demonstra o fluxo de criar uma sala, encontrá-la em outro dispositivo, entrar nela e trocar mensagens em tempo real.

## Funcionalidades entregues

- cadastro e login por e-mail e senha;
- busca de estudantes por disciplina e intenção;
- criação de salas de estudo com matéria, objetivo e limite de participantes;
- visualização e entrada em salas criadas por outras pessoas;
- chat em tempo real dentro da sala;
- mensagens diretas entre dois usuários localizados pelo e-mail cadastrado;
- publicação do site pelo GitHub Pages;
- armazenamento de contas, salas e mensagens no Firebase.

## Tecnologias utilizadas

- HTML para estrutura das telas;
- CSS para aparência e responsividade;
- JavaScript para as interações;
- Firebase Authentication para as contas;
- Cloud Firestore para salas e mensagens em tempo real;
- GitHub Pages para hospedagem.

## Critério de aceite da demonstração

O sistema é considerado pronto para demonstração quando duas pessoas, em dispositivos diferentes, conseguem criar contas, participar da mesma sala e visualizar as mensagens uma da outra sem atualizar a página.

# Retrospectiva

## O que funcionou bem

- A escolha por HTML, CSS e JavaScript permitiu criar um site fácil de abrir e demonstrar.
- A separação entre interface e Firebase tornou possível adicionar comunicação entre dispositivos sem reescrever as telas.
- Os fluxos de sala e conversa direta representam situações próximas da rotina de estudo.

## Desafios encontrados

- A versão inicial utilizava dados locais do navegador, o que não atendia uma demonstração com duas pessoas em dispositivos diferentes.
- A configuração de autenticação, banco de dados, regras e hospedagem exigiu atenção para que o acesso fosse permitido somente a usuários autorizados.
- Foi necessário testar os fluxos de criação de sala e entrada de participantes no ambiente publicado.

## Aprendizados

- Uma aplicação web simples pode evoluir gradualmente quando a interface é mantida separada do armazenamento de dados.
- Regras de acesso são tão importantes quanto as telas, pois protegem salas e conversas.
- Testar em dois dispositivos revela problemas que não aparecem em uma demonstração local.

## Melhoria para uma próxima iteração

Planejar os cenários de teste desde o início e registrar cada fluxo principal antes da apresentação final.
